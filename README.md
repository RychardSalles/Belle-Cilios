👁️ Belle-Cilios

Sistema web de agendamento online e painel administrativo desenvolvido para estúdios de extensão de cílios, automatizando a marcação de horários, catálogo de serviços e integração direta com o WhatsApp.

Acesse o site oficial: bellecilios.com.br

🚀 Funcionalidades

🌐 Site Principal (index.html)

Catálogo de Serviços: Exibição dinâmica de procedimentos estéticos especializados, valores e descrições.

Agendamento Inteligente: Seleção intuitiva de datas e horários disponíveis diretamente pelo telemóvel ou computador.

Redirecionamento para o WhatsApp: Envio automático de mensagens formatadas com os dados do cliente e detalhes do agendamento escolhido.

🔐 Painel Administrativo (admin.html)

Gestão de Horários e Serviços: Painel de controlo exclusivo para a administradora gerir a disponibilidade e os atendimentos do estúdio.

Autenticação Segura: Controlo de acesso protegido para garantir a segurança dos dados do negócio.

🛠️ Tecnologias Utilizadas

HTML5, CSS3 & JavaScript (ES6+): Estrutura e interatividade otimizadas para dispositivos móveis.

Firebase: Base de dados em tempo real e autenticação (veja o guia de configuração em CONFIGURAR-FIREBASE.md).
